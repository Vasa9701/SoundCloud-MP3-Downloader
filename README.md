## 🔧 Изменения в форке

В Windows-версии были внесены следующие изменения:

- Добавлен автоматический поиск **FFmpeg** в папке рядом со скриптом (`ffmpeg*/bin/`), без необходимости прописывать путь вручную.
- Изменена структура сохранения плейлистов:
  ```text
  Автор/
  └── Альбом/
      ├── Track 1.mp3
      ├── Track 2.mp3
- Поломал функцию создания обложек (Ранее на альбом скачивались обложки на каждый трек, сейчас нет обложек совсем)
